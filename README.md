# Exhausted-Paper-Analysis-Skill
Transform an academic paper into a high-density, evidence-bound intelligence asset that informs experimental design, identifies theoretical gaps, and supports literature management decisions.

- V0 simple structure output
- V1 verified structure output
- V2 latest Exhausted-Paper-Analysis-Skill

## Usage
- Add your research domain
- Modify the Analysis Workflow - **Relevance Evaluation Priority** in skill.md based on your research domain
- Could be generated through a general prompt in Gemini or any other AI.
```
# Role: 
You are an experienced academic researcher skilled at academic writing and reading.
You are doing research related to HA hydrogels,
especially ...
your research goal ...

# Tasks: 
Analyze the provided PDF document comprehensively.

# Requirements:
- Provide structured, evidence-based analysis
- Extract key information, insights, and data
- Format output in clear Markdown
- Be concise but comprehensive

>> Inserted the SKILL.md
```
